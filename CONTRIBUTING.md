# Contributing

Thanks for helping. Open an [issue](https://github.com/clerdoapp/clerdoframe/issues) for a bug or an idea, or send a pull request.

1. Read [AGENTS.md](AGENTS.md). The legal rules there are firm.
2. Set up with [docs/development.md](docs/development.md).
3. Keep each pull request to one change, with a test when it changes behaviour.

For something that looks wrong on a slide, a screenshot helps. For a file that opens badly, a small sample file helps most. Don't attach anything private.
