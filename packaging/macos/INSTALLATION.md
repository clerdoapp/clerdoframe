# Installing on macOS

Download `clerdoframe-<version>-mac-universal.dmg`, open it and drag **ClerdoFrame** to **Applications**. One file runs on both Apple-chip and Intel Macs.

The builds aren't code-signed yet. The first time, right-click the app, choose **Open**, then **Open** again. After that it opens normally.

To make ClerdoFrame open `.pptx` files by default: select a `.pptx` file in Finder, choose **File › Get Info**, pick ClerdoFrame under **Open with**, then **Change All…**.
