# Examples

Sample presentations made with ClerdoFrame. Rebuild them with `npm run examples`.

| File | What it shows |
|---|---|
| `welcome-tour.pptx` | A short tour of ClerdoFrame |
| `pitch-deck.pptx` | A startup pitch with charts |
| `lesson.pptx` | A classroom lesson |
| `report.pptx` | A quarterly report with tables and charts |
| `photo-album.pptx` | A photo album layout |
| `timeline.pptx` | A project timeline |
